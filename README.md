# ayed-step-leveling-site (Static GitHub Pages)

## ماذا يوجد هنا؟
موقع ثابت (بدون سيرفر) لاختبار تحديد المستوى (STEP) + تحليل النتائج + خطة مذاكرة + مشاركة + دعم.

## رفعه على GitHub Pages بسرعة
1) ارفع كل الملفات كما هي داخل جذر المستودع (Root).
2) من GitHub: Settings → Pages
3) اختر:
   - Source: Deploy from a branch
   - Branch: main / root (أو حسب مستودعك)
4) انتظر النشر، ثم افتح رابط Pages.

> ملاحظة: ملف `.nojekyll` موجود لتفادي أي معالجة من Jekyll.

## تشغيل محليًا (اختياري)
- افتح `index.html` مباشرة، أو استخدم أي static server بسيط.

## أهم الملفات
- `index.html` الرئيسية
- `quiz.html` الاختبار
- `results.html` النتائج + الخطة
- `bridge.html` التسجيل بالدورة (رابط خارجي)
- `support.html` الدعم
- `assets/data/question-bank.json` بنك الأسئلة (300 سؤال)
